## What's New

### GUI Version

A graphical user interface (GUI) has been introduced using **Tkinter**, replacing the command-line interaction with a more intuitive desktop application.

### New Features

* Desktop GUI built with Tkinter
* Dark theme interface
* Interactive playlist with MP3 file loading
* Double-click a song to start playback
* Current track display
* Play, Pause, Resume, and Stop controls
* Previous and Next track navigation
* Shuffle playback
* Adjustable volume slider
* Automatic detection of MP3 files from the `Music` directory
* Display of the total number of available songs
* Improved user interface with playback status updates

## Technologies

* Python 3
* Tkinter
* Pygame
* OS Module
* Random Module
