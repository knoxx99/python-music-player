## Features

* Command-line based music player built with Python and Pygame.
* Dynamic loading of MP3 files from a local music directory.
* Playback controls including play, pause, resume, and stop.
* Playlist navigation with next and previous track support.
* Shuffle functionality for randomized playback.
* Adjustable volume controls.
* Recently played tracks history.
* Input validation and error handling for improved user experience.

## Playback Controls

| Key | Function                       |
| --- | ------------------------------ |
| P   | Pause playback                 |
| R   | Resume playback                |
| S   | Stop playback                  |
| N   | Next track                     |
| B   | Previous track                 |
| H   | Shuffle playlist               |
| +   | Increase volume                |
| -   | Decrease volume                |
| L   | Display recently played tracks |

## Recent Enhancements

### Playback History

A playback history feature has been introduced to maintain a record of recently played tracks. Users can review the latest tracks played during the current session using the `L` command.

### User Experience Improvements

* Improved command interface.
